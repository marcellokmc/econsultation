# Télécharger Grenier Pro 2.0

Installateur Windows (Windows 10 ou 11, 64 bits) :
**[Grenier-Pro-Setup-2.0.1.exe](https://github.com/marcellokmc/econsultation/raw/claude/grenier-integration-tests-gowaki/grenier-pro/telechargement/Grenier-Pro-Setup-2.0.1.exe)** (22 Mo)

Empreinte SHA-256 (pour vérifier le fichier) : voir `Grenier-Pro-Setup-2.0.1.exe.sha256`.

1. Téléchargez le fichier sur un ordinateur Windows, puis double-cliquez dessus.
2. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » → « Exécuter quand même ».
3. Lancez « Grenier Pro » depuis l'icône du Bureau. Démonstration : menu Démarrer → « Grenier Pro (démonstration) »,
   connexion `owner@grenier.test` / `password`.
